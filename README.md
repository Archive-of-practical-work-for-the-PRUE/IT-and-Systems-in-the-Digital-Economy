## Задание 3. Искусственные нейронные сети

Активация: **логистическая функция**  
\( f(x) = \dfrac{1}{1 + e^{-x}} \)

Сумма на нейрон:  
\( \mathrm{net}_j = \sum_i w_{ij} \cdot x_i \)

Среднеквадратичная ошибка (n — число выходных нейронов):  
\( E = \dfrac{1}{n} \sum_{i=1}^{n} (V - V')^2 \)

Расчёты и схемы — на отдельных листах в `Себежко_задания Excel.xlsx`; скриншоты — в практикум.

### Задача 3.1 — сеть прямого распространения (вариант 1)

| Параметр | Значение |
|----------|----------|
| Входы | X1 = 1, X2 = −1, X3 = 3, X4 = 2 |
| Скрытые слои | 0 |
| Выходы | 2 нейрона (V1, V2) |
| Ожидаемые выходы | V1 = **1**, V2 = **1,5** |

**Веса (вариант 1):**

| Вес | Значение | Связь |
|-----|----------|--------|
| W1 | 0,5 | X1 → V1 |
| W2 | 0,7 | X1 → V2 |
| W3 | −0,2 | X2 → V1 |
| W4 | −0,1 | X2 → V2 |
| W5 | −0,4 | X3 → V1 |
| W6 | −0,1 | X3 → V2 |
| W7 | −0,1 | X4 → V1 |
| W8 | −0,9 | X4 → V2 |

**Выполнить:** схема сети в Excel → расчёт net → активация → V1, V2 → ошибка E → скриншот в практикум.

### Задача 3.3 — обратное распространение ошибки (backpropagation)

На основе сети из **задачи 3.1**.

| Параметр | Значение |
|----------|----------|
| Скорость обучения ε | 0,1 |
| Импульс α·ΔW | 0,01 (упрощение: α·ΔW_(i−1,j) = 0,01) |
| ε_(n+1) | ε_n / (1 + d_n) — по методичке |

**Шаги:**

1. Рассчитать ошибку E (как в 3.1).  
2. δ для выходных нейронов: \( \delta = E \cdot f'(x) \), где \( f'(x) = f(x) \cdot (1 - f(x)) \).  
3. Обновление весов: \( W_{ij}^{new} = W_{ij}^{old} + \Delta W_{ij} \),  
   \( \Delta W_{ij} = \varepsilon \cdot \mathrm{GRAD} + \alpha \cdot \Delta W_{i-1,j} \),  
   \( \mathrm{GRAD} = \delta_{i+1,j} \cdot f(x_{ij}) \).  
4. Повторный прямой проход с новыми весами.  
5. Новая ошибка сети.  

Скопировать схему 3.1 на новый лист, выполнить расчёты, приложить скриншот в практикум.
