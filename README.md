## Задание 4.3 — Нейронные сети на Python

Реализация задач **3.1** и **3.3** из Excel-практикума. Точность вычислений: **не менее 6 знаков** после запятой.

### Исходные данные (вариант 1, задача 3.1)

| Параметр | Значение |
|----------|----------|
| Входы | X1=1, X2=−1, X3=3, X4=2 |
| Ожидаемые выходы | V1=**1**, V2=**1,5** |
| Скрытые слои | 0 |
| Активация | логистическая: \( f(x) = 1/(1+e^{-x}) \) |

**Веса:**

| | → V1 | → V2 |
|---|------|------|
| X1 | 0,5 | 0,7 |
| X2 | −0,2 | −0,1 |
| X3 | −0,4 | −0,1 |
| X4 | −0,1 | −0,9 |

**Среднеквадратичная ошибка:**

\[
E = \frac{1}{n}\sum_{i=1}^{n}(V - V')^2
\]

### Подзадача 1 — прямое распространение (задача 3.1)

1. Вывести название задачи, ФИО, группу, вариант.
2. Дату — через модуль **`datetime`**.
3. Исходные данные (входы, веса, ожидаемые выходы).
4. Рассчитать **net**, активацию, **V1**, **V2**, ошибку **E**.

**Пример результата (вариант 1):**

```
Входной слой: [1, -1, 3, 2]
Суммарное воздействие V1: -0.700000  →  V1: 0.331812
Суммарное воздействие V2: -1.300000  →  V2: 0.214165
Ошибка сети: 1.049923
```

### Подзадача 2 — backpropagation (задача 3.3)

Параметры обучения (по методичке):

| Параметр | Значение |
|----------|----------|
| Скорость обучения ε | 0,1 |
| α·ΔW (упрощение) | 0,01 |
| Число циклов | **≥ 100** |

**Алгоритм:**

1. Вывести исходные веса, значения нейронов, начальную ошибку.
2. В цикле (≥100 итераций): обновить веса по backpropagation, пересчитать выходы и ошибку.
3. После каждого цикла — **пустая строка** в выводе.
4. Построить **график снижения ошибки**; на графике видно **ФИО**; на скриншоте — **новая ошибка** сети.

**Производная сигмоиды:** \( f'(x) = f(x) \cdot (1 - f(x)) \)

**Обновление веса:**  
\( W_{new} = W_{old} + \varepsilon \cdot GRAD + \alpha \cdot \Delta W \)
